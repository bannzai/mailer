## Platform
- iOS/macOS/CLI

## 課題
- GmailクライアントだとiOSアプリに都度通知がくるのが大変
- その場でlabel分して、Inboxに入らないようにしたいが、操作が大変
- 通知センターから気がれるにArchiveしたい(タイトル読んだだけで判断できるものも多いから)

## Gmail Utility
- Gmailのlabelを素早く分ける。用途としては、不要なメールをInboxに置かないため。一致するメールもlabel作成時に自動で移動する
- 通知フィルタリング: 来たメールを都度通知するのではなくて、12時間に1回通知などの設定をしたい。そのための枠(メールアドレス、件名などで合致したもの)を作り対象にする
- いつの間にか購読されているメルマガなどで、Unsubscribe 機能があるドメインであれば、自動でUnsubscribeできたりできないかなと考えている。リンクを踏めば解決するので。これはもちろんユーザーが手動で許可をする機能

## Account
- 複数アカウントを分かりやすく管理・スイッチできるようにしたい
- 通知がアカウント単位でグルーピングされている

## V2
- 現在は主にGmailアカウントを使っているが、そのうち独自ドメインのメールアドレスも持ちそうなので、そうなった場合に同じことができるようにしたい
